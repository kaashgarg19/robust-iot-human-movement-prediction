# Basic Methodology

The project follows a simple machine-learning workflow.

## 1. Load the data

The environmental IoT sensor dataset is loaded into Python using Pandas.

## 2. Check and prepare the data

The dataset is checked for its structure, data types, missing values and basic data quality issues. The timestamp and device information are prepared for analysis.

## 3. Explore the data

Sensor readings are explored using summary statistics and visualisations to understand the data and the movement field.

## 4. Prepare features

Relevant sensor and device information is prepared as inputs for machine-learning models.

## 5. Train models

Machine-learning classification models are used to predict whether human movement is recorded.

## 6. Compare results

The model outputs are compared using appropriate evaluation measures.

## Tools used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

This page describes the basic project workflow. Detailed experiments and later research extensions are documented separately from the original MSc methodology.
