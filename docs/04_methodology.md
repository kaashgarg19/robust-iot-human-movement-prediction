# Basic Methodology

The project follows a straightforward machine-learning workflow.

```text
Sensor data
    ↓
Data preparation
    ↓
Data exploration
    ↓
Model training
    ↓
Model evaluation
```

## 1. Data preparation

The IoT sensor data is loaded and checked for its structure, fields and data quality.

## 2. Data exploration

The sensor measurements are examined using basic statistics and visualisations to understand the data.

## 3. Preparing the model data

The relevant sensor measurements are used as input features, and `motion` is used as the prediction target.

## 4. Model training

Classification models are trained using the prepared data.

## 5. Evaluation

The model results are compared using classification measures and recorded with the project results.

## Tools

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
- Matplotlib

This page describes the basic MSc project workflow. Detailed research experiments are documented separately and are not presented as part of the original MSc methodology.
