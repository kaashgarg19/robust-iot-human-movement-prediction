# Reproducibility

The project is being organised so that the source of the data, original MSc work and later research work can be identified separately.

## Data

The raw CSV is not stored in this repository.

To reproduce the work, obtain the **Environmental Sensor Telemetry Data** dataset from its original Kaggle source and use the dataset described in [Dataset](03_dataset.md).

## Original MSc work

The original Python implementation is stored in [Aman.py](../original_msc/Aman.py).

The original dissertation is stored in [the dissertation folder](../original_msc/dissertation/).

## Environment

The work uses Python and common data-science libraries including:

- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Reproduction notes

The original MSc implementation and the later research extension are separate.

The original dissertation should be used to understand the 2021 experiment as it was originally completed. Later experiments should be documented separately rather than treated as part of the original MSc submission.

As the project develops, exact experiment settings, software versions and result files will be added when they are ready.
