# Research Figures

This folder contains publication-style, lightweight SVG figures for the research repository.

## MSc figures

- `msc_model_accuracy.svg` — reconstructed model-accuracy comparison from the reported MSc output.
- `msc_research_bridge.svg` — visual bridge from the original MSc project to the current robustness research question.

These figures are **reconstructions**, not scans or exact copies of the dissertation screenshots. The dissertation itself contains the original figures and source screenshots.

The repository will later add canonical research-extension figures for:

- precision-recall performance
- chronological vs random evaluation
- unseen-device generalisation
- feature ablation
- threshold sensitivity
- uncertainty/calibration
